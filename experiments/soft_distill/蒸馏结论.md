# 软标签蒸馏(强融合 → RealMLP)— 结论

日期: 2026-10-25

## 有效结论(三臂, fold 0 + fold 1 一致)

教师 = route + context + TabM(在 fold 1-9 嵌套 5 折 CV 生成 OOF),rank 融合(0.3/0.3/0.4)+ Isotonic 校准。
学生 = lean RealMLP(数值双表示 + count + combo + 折内 TE + drop),软目标经 ToSoftLabelLayer 透传注入。

| 指标 | fold 0 | fold 1 |
|---|---|---|
| Δ(B−A) 蒸馏 vs 标准 | +0.000056 | +0.000039 |
| Δ(B−C) 蒸馏 vs 均匀平滑 | +0.000210 | +0.000143 |
| Δ(C−A) 平滑 vs 标准 | −0.000154 | −0.000103 |

三臂 AUC(fold 0 / fold 1):
- A 硬标签: 0.961606 / 0.961660
- B 80%标签+20%教师: 0.961662 / 0.961700
- C 80%标签+20%先验: 0.961452 / 0.961557

### 结论
1. **B > A**(+0.00004~0.00006, 两折一致):教师软标签对学生有**可复现的弱正信号**,但量级低于 ~0.000125 门槛。
2. **B > C**(+0.00014~0.00021, 两折一致, 越过门槛):增益来自**教师信息**,不是均匀平滑(C 本身为负)。
3. **C < A**:均匀标签平滑是负的,是好的对照。

## 边界(重要)

- **B 加入自有融合的边际贡献未测**:边际测试脚本 `fusion_marginal.py` 里 B 的特征集与蒸馏不一致(B 实测 0.960,蒸馏为 0.9617),是较弱学生,其"降分"结果无效,不能作为结论。
- 本对照用的是**旧三腿 rank 融合(0.9614)**,不是公榜 0.96126 的完整自有融合。
- "学生来自教师所以必然冗余"是**解释假设,未证实**,不写进结论。
- 此结果**不能证明公开方案空间已饱和**。

## 技术沉淀(可复用)

软目标注入 PyTabKit 训练的正确方式:
1. `cross_entropy`(metrics.py)对 float y 走软目标分支;
2. `ToSoftLabelLayer`(nn.py)对 float y 直接透传(只对整数 y 做 one-hot);
3. 所以 monkey-patch `ToSoftLabelLayer.forward_tensors` 让 float y 透传 + 在原始 ds 层注入 float 软目标 [n,2],即可在不改动训练器(flat_anneal/优化器/参数组/n_ens)的前提下做蒸馏。
4. A(硬 one-hot 软目标)已验证复现原训练(Δ < 1e-4)。
