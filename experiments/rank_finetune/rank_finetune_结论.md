# 基础网络排序目标微调 — 结论

日期: 2026-10-25

## 结论

fold 0、RealMLP 精简配方、lr=0.005 × 500 步:继续 CE 与 pairwise 排序微调均使 AUC 下降
(A 0.961601 > B 0.960691 > C 0.960487),排序目标无正信号,停止该配置。

## 三臂结果(同折、同预算、同优化器、同随机状态)

| 臂 | AUC | Δ vs A |
|---|---|---|
| A 冻结原模型 | 0.961601 | — |
| B 继续交叉熵微调 | 0.960691 | −0.000910 |
| C pairwise 排序微调 | 0.960487 | −0.001114 |

- Δ(C−B) = −0.000204

## 解读

- B(继续 CE)已略降,说明 3 epoch 后模型已到位,额外训练过拟合;
- C 比 B 还低,说明**换成对排序损失不仅没带来有用排序,反而更差**——不是"额外预算"的问题,是排序目标本身对 RealMLP 基座不适用。

## 边界

- 单折、固定小预算(lr=0.005 / 500 步),未做 lr/步数搜索;
- 初筛目的是看有无正信号,结果是**明确负**(C < B < A),非噪声级,无需扩大搜索抢救;
- 只否定「RealMLP 基础网络 + 成对 logistic 排序损失」这一具体假设,不否定其他排序微调形式或别的基座。

## 技术前提(已验证)

- 方案 A(走 PyTabKit 内部)可行:state_dict 提取 + 复用 `m.x_converter_` + softmax-per-member 集成顺序,手动 forward 与 predict_proba diff = 0。
