# S6E10 独立复现排查总结

日期：2026-10-09。本文件归档整条「漏掉的杠杆」独立复现的结论、脚本与最终成绩。

## 背景与起点

- 竞赛：Playground S6E10 航空满意度，二分类 ROC-AUC，train 699,635×23 / test 299,844×22。
- **自有模型天花板**：LB 0.96100（三路融合 route_aux + context + tabm，rank-blend）。
- 抄公开（Busy53 全开源）到 LB 0.96169；榜一 0.96177。
- 复盘认定 gap 主要来自三个「漏掉的杠杆」：原始数据逐列 lookup、digit 特征、调对的 RealMLP。本轮逐一独立复现验证。

## 关键方法教训

1. **报告结论别过度断言**：只写「未显示增益 / 停止当前配置」，不写「判死 / 无增益 / 特征饱和坐实 / 硬件天花板」；区分「已验证机制」和「合理假设」。此教训本会话被纠正多次，已固化为 memory `no-overclaiming-results`。
2. **测量增益用配对 DeLong/bootstrap**，别只看 OOF 差值；单折/两折单种子 Δ 常落在噪声内。
3. **特征消融要 proper 嵌套**：内层选轮数用独立的特征/TE（不与外层共享），否则 val 早停会泄漏、增益偏乐观。早期 digit 的伪正信号正是单套 TE 内外层共用造成的。
4. **基线要一致**：同一候选在「树融合」vs「50/50」vs「0.96125 方案」下边际不同（深层 LGBM 在树融合上 +0.000030、换 50/50 后 +0.000019 掉到门槛下）。
5. **n_ens 已覆盖集成收益**：RealMLP 第二种子无增益（Δ −0.0000123，p=0.26）。
6. **公开公式有坑**：digit 的 `v//(10**k)%10`（k<0）在整数数据上恒输出 9，是浮点 bug；TE 在 sklearn 1.9 里 `shuffle/random_state` 已弃用（仅警告）。

## 剩余 gap（0.00043）的说明

剩余的 0.00043 主要来自公开方的基础模型（full-context TabPFN，需 GB10 级显存）与 48 成员集成 + 更系统的权重搜索，不在本机（RTX 5060 8GB）能独立复现的范围内。特征侧、可独立训练的 NN/GBDT 侧、融合层正则（成对排序/非负/分组）、新增公开成员（sachith7）均已试过且无增益——**0.96169 这个公开天花板在本机推不动**。
